# Entidades Paranormais

Jogo de ação com terror em terceira pessoa (navegador, em blocos com textura em pixel). Agora: o **Criador de mapas** do Modo desenvolvedor.

## Rodar

Precisa do [Node.js](https://nodejs.org) 18 ou mais novo.

```bash
npm install
npm run dev
```

Abra o endereço que aparece (normalmente http://localhost:5173).
Menu → **Modo desenvolvedor** → **Criador de mapas**. O mapa "Sala de teste" vem de exemplo (`maps/teste/`).
